# 单词闯关 · English Lianxi

> 看句子、补空格，像玩游戏一样把单词练进脑子。

单文件离线网页，双击 `English_lianxi.html` 就能练，不用安装任何东西，也不用联网。

![首页](https://gcore.jsdelivr.net/gh/LPP159/english-lianxi@b1fbe80/screenshots/home.png)

## 核心玩法

句子里挖掉的那个空，就是你要打的单词。

![练习](https://gcore.jsdelivr.net/gh/LPP159/english-lianxi@b1fbe80/screenshots/practice.png)

- 打满正确答案的长度就**自动判题**，不用按回车
- 连对累积 🔥 连击，一次不错给 **PERFECT**，用了提示降为 GOOD
- 打错不会「看不出差在哪」：正确答案和你填的内容会**逐字母比对**，错处直接标出来
- 打错的词自动进错词本，下一轮优先考这些
- 结算给星级、正确率、最高连击

## 功能

| 功能 | 说明 |
|---|---|
| 词表库 | 内置 160 词；可导入任意多份自己的词表，随时切换，互不覆盖 |
| 判题 | 满长度自动判，逐字母 diff 标注 |
| 提示 | `Tab` 逐字母提示（不替你打字），`Esc` 跳过 |
| 朗读 | 点 🔊 听发音，用浏览器语音合成，不需要音频文件 |
| 进度 | 每份词表各自保存暂停点；单词掌握度按单词累计 |
| 存档 | localStorage 本地保存，刷新/关浏览器都不丢 |
| 音效 | WebAudio 实时合成，无外部音频 |

## 快速开始

1. 下载或 clone 本仓库
2. 双击 `English_lianxi.html`
3. 点「开始练习 · 20 题」

需要 Chrome / Edge 等现代浏览器。玩法是键盘打字，**建议在电脑上用**。

## 自己的词表

内置的 160 个词来自一份线下词表（PDF 未随仓库分发）。想练别的内容：

1. 首页底部「词表库」→「＋ 导入词表」
2. 支持 **CSV / TSV / JSON / Markdown 表格**，表头中英文都认
3. 新词表会加进词库并自动切换，原来的都保留

格式细节见 [生词表格式说明.md](生词表格式说明.md)。仓库里有两份现成文件：

- [第一天词表.csv](第一天词表.csv) —— 内置 160 词的完整七列，照着改最省事
- [测试词表.csv](测试词表.csv) —— 9 行里故意留了 2 行错的，导入后应提示「共 7 词，跳过 2 行」，可以用来确认导入功能没坏

最省事的写法：**一个单词一行，必须有一条例句，例句里用一个 `___` 挖空。**

## 快捷键

| 键 | 作用 |
|---|---|
| 字母 | 拼写 |
| `Enter` | 确认 / 下一题 |
| `Tab` | 提示首字母 |
| `Esc` | 跳过 |
| `Backspace` | 删一个字母 |
| `L` | 首页打开生词表 |

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，**无框架、无构建、无 npm 依赖**
- 单文件约 78 KB，所有逻辑与内置词表都在里面
- 音效用 WebAudio 实时合成，朗读用 `SpeechSynthesis`
- 全部数据存在浏览器本地，不上传任何服务器
